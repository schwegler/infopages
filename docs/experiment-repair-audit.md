## Coverage and evidence

- Six actual experiments at 390, 768 and 1440px: 18 responsive interaction scenarios, every local navigation target, all original controls and returned result states.
- Existing all-page checks cover 11 routes at 1536, 390 and 320px, including expanded disclosures, same-origin asset loading and absence of personal Bluesky profile links.
- History tests cover filtered counts, character-dialog keyboard behavior and focus return, failed data load/retry, empty data selection, and rendering untrusted dataset text safely.
- SQL tests check all three permission outcomes and reset; payload text never becomes executable HTML.
- Migration tests complete all four assessment checks, render the original comparison, switch every security topic, and finish/reset all seven rehearsal steps.
- Research tests switch every year/demographic/cause and verify visible charts and accessible tables.
- Native mascot disclosures verify the approved PNG decodes at 1145 × 1374 and displays at 96 CSS pixels. No generated replacement or vector mascot.
- Six unit tests include chart zero-baseline/spacing calculations alongside original model behavior.
- The print résumé was rendered and visually inspected as one A4 page with the new email address.

`artifacts/experiments/` contains first-view and result screenshots at all three widths, plus every TNA chart view, history character dialog and thematic charts. CI uploads this folder as part of `site-qa`. Selected phone before/after comparisons are committed under `docs/screenshots/experiment-repairs/`; full before captures remain in the review ZIP. These screenshots are evidence, not automated pixel-diff assertions.

## Content boundaries

The original illustrative values are unchanged. TNA charts lack an independently verified historical methodology. Fading Spaces geography/trend values are representative illustrations from the old code, not verified venue counts. Hollyoaks retains its original 25-event data, which runs through 2016 despite the “first 20 years” title; the introduction states that scope. This repair does not invent or independently validate those figures.

The résumé title/dates remain conservative pending confirmation. Professional/social separation remains intact: project links about Bluesky are preserved, direct personal Bluesky profile links are absent. DNS, production configuration, authentication and mail routing are unchanged.
